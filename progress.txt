# Progress Log

## Learnings
(Patterns discovered during implementation)
- Migrations use pattern: `NNN_description.sql` in supabase/migrations/
- RLS policies wrapped in DO $$ BEGIN ... EXCEPTION WHEN duplicate_object THEN NULL; END $$; for idempotency
- Use `update_updated_at_column()` function for updated_at triggers (defined in 001 migration)
- No local Supabase/Docker available - test migrations by build pass only
- Build command: `npm run build` (no typecheck script available)

## Iteration 2 - US-002: Initialize credits for new companies
- Modified `api/register-company.ts` to create `company_analysis_credits` record after company creation
- Set `free_analyses_remaining: 5` and `purchased_credits: 0`
- Used `upsert` with `onConflict: 'company_id'` and `ignoreDuplicates: true` for idempotency
- Credits creation failure is logged but doesn't fail registration (non-critical path)
- Files changed: api/register-company.ts, PRD.md
- Learnings for future iterations:
  - Supabase upsert with `ignoreDuplicates: true` is good for idempotent operations
  - Non-critical operations (like credits init) should log errors but not fail the main operation

## Iteration 3 - US-003: Add credit check to analyze-job API
- Added `company_id` (UUID) as required parameter to `JobAnalysisRequest` schema in `api/analyze-job.ts`
- Added `checkCredits()` function to query `company_analysis_credits` table
- Returns 402 with `{ error: 'No analysis credits remaining', code: 'CREDITS_EXHAUSTED' }` if no credits
- Added `X-Credits-Remaining` header to streaming response via `toTextStreamResponse({ headers: {...} })`
- Files changed: api/analyze-job.ts, PRD.md
- Learnings for future iterations:
  - Supabase `single()` returns PGRST116 error code when no record found
  - The AI SDK's `toTextStreamResponse()` accepts a `headers` option for custom response headers
  - For streaming responses, add headers via the options object, not by creating a new Response

## Iteration 4 - US-004: Deduct credits after successful analysis
- Added `deductCredit()` function to deduct 1 credit after streaming completes
- Deducts from `free_analyses_remaining` first (if > 0), else from `purchased_credits`
- Creates entry in `analysis_usage_logs` with job_title and credit_type ('free' or 'purchased')
- Updates `company_analysis_credits.updated_at` timestamp
- Uses AI SDK `onFinish` callback in `streamText()` to trigger deduction after stream completion
- Files changed: api/analyze-job.ts, PRD.md
- Learnings for future iterations:
  - AI SDK `streamText()` accepts an `onFinish` callback that fires when streaming completes successfully
  - For credit deduction, pass the current free balance to determine which type to deduct
  - Errors in `onFinish` should be logged but not thrown (streaming already succeeded)
  - Use sequential fetch-then-update approach for Supabase (no direct decrement operation)
