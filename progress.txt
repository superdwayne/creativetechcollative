## Iteration 5 - US-029: Trigger profile enrichment on creation
- What was implemented:
  - Created new API endpoint `/api/enrich-profile.ts` for single profile enrichment
  - Endpoint validates user owns the profile, generates OpenAI text-embedding-3-small embedding from profile data
  - Modified `NetworkCreateProfilePage.tsx` to call enrichment endpoint after successful profile creation
  - Added `isEnriching` and `enrichmentError` state for tracking enrichment status
  - Added "Enhancing your profile with AI..." message with Sparkles icon during enrichment
  - Added warning message if enrichment fails (graceful degradation - profile creation still succeeds)
  - Enrichment runs in background after profile creation succeeds
- Files created:
  - api/enrich-profile.ts (new single-profile enrichment endpoint)
- Files changed:
  - src/pages/NetworkCreateProfilePage.tsx (added session import, enrichment state, enrichment call in handleSubmit, enrichment status UI)
- Learnings for future iterations:
  - Session comes from `useAuth()` hook and provides `access_token` for API authentication
  - API calls to `/api/*` endpoints use `Authorization: Bearer ${session.access_token}` header
  - Graceful degradation pattern: try/catch around enrichment, set error state but don't throw
  - Sparkles icon with `animate-pulse` class for loading states
  - AlertTriangle icon with amber colors for warnings
  - Embedding is generated from: name, bio, skills, focus_areas, projects, location, enriched_content

## Iteration 6 - US-030: Trigger profile enrichment on update
- What was implemented:

  - Shows "Updating your AI profile..." message with Sparkles icon during enrichment
  - Shows warning with AlertTriangle icon if enrichment fails (graceful degradation)
  - Added Sparkles and AlertTriangle icons to imports
- Files changed:
  - src/pages/NetworkEditProfilePage.tsx (added enrichment state, URL tracking, enrichment call in handleSubmit, enrichment status UI in success screen)
- Learnings for future iterations:
  - Track original field values at load time to detect changes on submit
  - Same enrichment pattern used in both create and edit flows for consistency
  - The `/api/enrich-profile` endpoint handles both create and update scenarios
